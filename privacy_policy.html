InkTeX

Privacy Policy

Effective date: March 5, 2026

✦ InkTeX collects no user data whatsoever. Everything happens locally on your device. Nothing is ever transmitted to any server.

What InkTeX Does

InkTeX is a Chrome extension that lets you draw mathematical equations on an HTML5 canvas, recognises the symbols using a locally-running neural network, and returns a LaTeX string and numerical answer — all inside your browser.

Data Collection

InkTeX does not collect, store, transmit, or share any of the following:

  • Drawings or canvas content
  • Equations or mathematical expressions
  • LaTeX strings or computed answers
  • Browsing history or page content
  • Device identifiers or IP addresses
  • Cookies or any persistent local storage

Local Processing Only

All inference is performed entirely on-device via ONNX Runtime WebAssembly. The trained model (.onnx) and all JavaScript assets are bundled with the extension and loaded from your local machine. No network request is made during symbol recognition or expression evaluation.

Permissions

InkTeX requests no browser permissions. It does not request access to tabs, browsing history, clipboard (the copy button uses the standard Web Clipboard API, which operates locally), or any other sensitive browser APIs.

Third-Party Services

InkTeX uses no third-party analytics, advertising, or tracking services. The extension loads the DM Sans typeface from Google Fonts on first open — this is the only outbound request the extension makes, and it is a standard font CDN request that carries no user- identifying payload beyond your IP address. It can be avoided entirely by using the extension offline, in which case system fonts are used as fallback.

Children's Privacy

Because InkTeX collects no data at all, it has no special considerations with respect to children's privacy.

Changes to This Policy

If this policy ever changes, the updated version will be posted at this URL with a revised effective date. Given that InkTeX collects no data, material changes are unlikely.
